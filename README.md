# Анализ веса — дашборд состава тела

Интерактивный дашборд динамики состава тела по отчётам умных весов «life».
Собран на [CoreUI 5](https://coreui.io) (Bootstrap 5) + Chart.js, один файл `index.html`, без сборки.

**Живая версия:** https://stanislavtsys21.github.io/weight-dashboard/

## Что внутри
- KPI-карточки со спарклайнами и историей по каждому показателю
- Инсайты за период (вес, жир/мышцы, безжировая масса, выбросы)
- Динамика любого из 15 показателей с полосой нормы
- Шкалы-спидометры и линейные шкалы «Низкое / Стандарт / Высокое» по каждому замеру
- Карта тела: тепловая раскраска рук, туловища и ног по % от нормы (мышцы / жир)
- Сегментарный анализ, радар «профиль тела», состав тела, тип телосложения
- Сравнение двух любых замеров, полная таблица, тёмная тема, печать в PDF

## Как добавить новый замер
Все данные лежат в начале `<script>` в `index.html`: массивы `DATES`, `LBL`, объект `M` (значения по показателям), `BODYTYPE`, `SEG` (сегменты). Добавь по одному элементу в каждый массив, остальное пересчитается само.
